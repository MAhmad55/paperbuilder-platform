## Common Layout Template (BWP Style)

All subjects follow the BISE Bahawalpur visual template:
1. **Header:** Bordered table, 3 cols (EN | Center | UR)
   - Row 1: Institute | Exam Session | (Urdu)
   - Row 2: Subject (EN) | Class | Subject (UR)
   - Row 3: Time + Marks (EN) | Roll No boxes | Time + Marks (UR)
   - Row 4: Student Name | Date | (Urdu)
2. **Note box:** Bordered, EN/UR side-by-side
3. **MCQs:** Q# in right narrow column, EN/UR side-by-side, options (A)(B)(C)(D) in row
4. **Short/Long:** "سوال نمبر N" right-aligned, EN/UR side-by-side, bordered rows
5. **Section headers:** "حصہ اول (Part-I)" boxed style
